# Focus Desk

A focus timer, task list and notes page. One file, no build step. Works on phones and computers.

Your tasks, notes and settings are saved in the browser on the device you use.

## Publish with GitHub Pages

1. Create a new repository on GitHub (for example `focus-desk`).
2. Upload `index.html` and `README.md` to it (Add file > Upload files).
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch", pick the `main` branch and the `/ (root)` folder, then Save.
5. After a minute your site is live at `https://YOUR-USERNAME.github.io/focus-desk/`.

## Use it on your phone

Open that address in your phone browser. To keep it like an app:

- Android (Chrome): menu > Add to Home screen.
- iPhone (Safari): Share > Add to Home Screen.
